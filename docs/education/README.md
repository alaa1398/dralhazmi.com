# Patient education sources

Working files behind the `/learn/` guides. The site content itself is in `src/data/education/`.

- `BRIEF.md`: the brief each drafting agent followed.
- `preparing.md`, `diet-stages.md`, `vitamins.md`, `warning-signs.md`: each guide's draft with full references, `[CHAIR]` decisions and Ali's evidence review.
- `CHAIR_DECISIONS.md`: every open decision across the four guides, with options and sources.
